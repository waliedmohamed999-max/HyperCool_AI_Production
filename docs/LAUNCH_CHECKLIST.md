# قائمة تجهيز Frost للنشر

قائمة عملية للتشغيل على Hostinger (أو أي استضافة Node). كل بند قابل للفحص، وما لا يمكن للكود ضبطه بنفسه مكتوب صراحةً كإجراء يدوي.

## 1) متغيرات البيئة (لوحة الاستضافة → Environment Variables)

الأمر `npm run production:check` يفحصها ويعطي **BLOCKER** لأي بند ناقص.

| المتغير | القيمة | لماذا |
|---|---|---|
| `NODE_ENV` | `production` | يغلق مسارات التطوير (مثل تجاوز CAPTCHA) |
| `PUBLIC_ORIGIN` | `https://<نطاقك>` (بدون مسار) | يفعّل كوكيز `Secure` والتحقق من المضيف، ويملأ روابط OG وcanonical وsitemap في الصفحة العامة |
| `DATA_DIR` | مسار **دائم** خارج مجلد النشر، مثل `/home/<user>/domains/<domain>/frost-data` | قاعدة SQLite تعيش هنا، والمسار الافتراضي داخل المستودع يُمسح عند إعادة النشر |
| `INTEGRATION_ENCRYPTION_KEY` | `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` | تشفير رموز OAuth؛ لا تعيد استخدامه بين البيئات، وتغييره يفصل كل التكاملات |
| `PLATFORM_ADMIN_USERNAMES` | اسم/أسماء مستخدمي مدير المنصة (راجع .env.example للصيغة) | بدونه صفحتا "منصة Frost" و"منشئ التكاملات" غير متاحتين لأحد |
| `SYSTEM_MODE` | `PRODUCTION_SAFE` لأول إطلاق | يحدّد سقف استقلالية كل وكيل عند L1 حتى يثبت سجل نظيف |
| `PLATFORM_RESEND_API_KEY` + `PLATFORM_MAIL_FROM` | مفتاح Resend وعنوان مرسِل من نطاق موثّق | بدونهما لا تصل رسائل التأكيد وإعادة التعيين والدعوة |
| `PLATFORM_MAIL_TRANSPORT` | **اتركه فارغًا** | `capture` للاختبار فقط |

اختياري لكن موصى به: تفعيل CAPTCHA (Turnstile) إن كان التسجيل العام مفتوحًا، وضبط `ALLOW_PUBLIC_SIGNUP` حسب رغبتك.

## 2) قبل الرفع
- [ ] `npm run build` ينجح.
- [ ] `npm test` كله أخضر.
- [ ] `npm run test:e2e` كله أخضر (تسع رحلات).
- [ ] `npm run production:check` بلا BLOCKER على بيئة الإنتاج نفسها.
- [ ] نسخة احتياطية من قاعدة البيانات الحالية: `npm run backup` (الترحيلات إضافية فقط، لكن النسخة لا تكلف شيئًا).

## 3) بعد النشر: تحقق فوري
```
curl -sI https://<نطاقك>/            # 200 وترويسة Content-Security-Policy
curl -s  https://<نطاقك>/ | grep -E "og:image|canonical"   # روابط مطلقة بنطاقك، ولا {{ }}
curl -s  https://<نطاقك>/robots.txt   # Disallow: /app و /api/ + سطر Sitemap
curl -s  https://<نطاقك>/sitemap.xml  # <loc> بنطاقك
curl -s  https://<نطاقك>/site.webmanifest
curl -sI https://<نطاقك>/assets/og-frost.png   # 200 image/png
curl -sI https://<نطاقك>/app          # 200
```
- [ ] سجّل الدخول على `/app` وتأكد أن الشريط الجانبي وغرفة القيادة والمشاريع تعمل.
- [ ] إن ظهر 503: افتح Runtime Logs (نجاح البناء لا يعني أن الخادم بدأ).
- [ ] أنشئ حساب المالك الأول فور النشر — أول مالك متاح لأول زائر.
- [ ] شارك رابط الصفحة العامة في أداة معاينة (مثل مصحّح OG لفيسبوك أو Card Validator لـX) وتأكد من ظهور صورة Frost.

## 4) ملاحظات تشغيلية
- **كاش الأيقونات:** ملفات `.png` تُخدَم بكاش سنة كاملة (immutable). لذلك كل مرجع لها يحمل `?v=frost1`؛ عند تغيير الأيقونات مستقبلًا غيّر رقم الإصدار في `site.webmanifest` و`index.html` و`home.html`، أو أعد التوليد بـ `node scripts/generate-brand-assets.mjs` مع رفع الرقم.
- **صورة المشاركة والأيقونات:** تُولَّد من `public/favicon.svg` بالأمر `node scripts/generate-brand-assets.mjs`.
- **نسخة واحدة فقط** من التطبيق مع SQLite، والمجدول يعمل داخل نفس العملية.
- **الترحيلات:** تعمل تلقائيًا عند الإقلاع وهي إضافية (أعمدة/جداول جديدة)، ولا تحذف بيانات.

## 5) إجراءات خارجية لا يستطيع الكود تنفيذها
- [ ] تحديث اسم التطبيق وشعاره وشاشة الموافقة (OAuth consent) في Meta وX وLinkedIn وSalla وMicrosoft. لا تغيّر أي redirect أو webhook URL دون اختبار.
- [ ] عنوان المرسِل واسمه في Resend (Frost) وتوثيق النطاق.
- [ ] حسابات السوشيال في `docs/project-scope.md` (مرجع للمتجر وليست جزءًا من المنصة).
- [ ] تحديث وثائق التسليم وأدلة الربط المسمّاة `HyperCool_*` إن أردتها بالاسم الجديد.

## 6) بنود مفتوحة تحتاج قرارك
- **صفحات قانونية:** لا توجد صفحة شروط استخدام أو خصوصية، والتذييل يفتقر لوسيلة تواصل حقيقية. لم أخترع نصًا قانونيًا أو بريدًا؛ أعطني النصوص وبيانات التواصل لإضافتها.
- **اسم المنشأة الافتراضي:** الصف المزروع للمستأجر الأول اسمه `HyperCool` (يظهر في الإعداد الموجّه وبريد الدعوة). تغييره قرار بيانات (لا يوجد مسار لإعادة تسمية المنشأة).
- **الموقع العام بالعربية فقط:** لا توجد نسخة إنجليزية ولا مبدّل لغة.
- **أسماء العميل في موجّهات الوكلاء:** كلمة HyperCool في `agents/*.md` تعني متجر العميل، وأُبقيت عمدًا.
- **التسجيل العام:** مفتوح افتراضيًا؛ راجع `ALLOW_PUBLIC_SIGNUP` وحدود التسجيل قبل الإعلان.
- **تقييد أدوات الفحص:** رحلة `npm run test:ui` (واجهة الفحص الشامل) ما زالت قديمة من خطوة الجدولة وما بعدها، وتغطي رحلات `test:e2e` الوظائف نفسها.
