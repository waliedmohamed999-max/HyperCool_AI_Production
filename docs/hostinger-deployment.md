# تشغيل HyperCool على Hostinger

يعالج هذا التحديث خطأ `ERR_REQUIRE_ASYNC_MODULE`: مشغل LiteSpeed يستخدم `require()`، لذلك نقطة الدخول هي `app.cjs` التي تستورد التطبيق بواسطة `import()` ثم تبدأ السيرفر صراحة. لا تختَر `src/server.js` كنقطة دخول للاستضافة.

## إعدادات النشر

- الفرع: `main`، مجلد المشروع: `./`.
- ملف الدخول (Entry file): `app.cjs`.
- أمر البناء: `npm run build`؛ أمر التشغيل إن ظهر: `npm start`.
- لا تستخدم `workflows:build` لبناء التطبيق؛ هذا الأمر يولد ملف n8n فقط.
- الإصدار المطلوب حاليًا: Node.js 24.11.0 أو أحدث. سجل الاستضافة أظهر 24.6.0؛ إصلاح الدخول لا يعني اعتماد هذا الإصدار الأقدم دون اختبار.

## متغيرات البيئة

```dotenv
PUBLIC_ORIGIN=https://hotpink-eagle-491767.hostingersite.com
HOST=0.0.0.0
DATA_DIR=/home/u196429893/domains/hotpink-eagle-491767.hostingersite.com/hypercool-data
```

مسار DATA_DIR أعلاه مقترح بناءً على المسار في السجل، وليس مسارًا تم التحقق من صلاحياته. يجب أن يكون قابلًا للكتابة من التطبيق ومستمرًا بين عمليات النشر وخارج `hbuilds/versions`. تحقق من استمرار البيانات لدى الاستضافة قبل الاستخدام الفعلي. لا تستبدله بـ `/tmp`. التطبيق ينشئ المجلد تلقائيًا إن كانت الصلاحيات تسمح. عند وجود قاعدة بيانات مستخدمة مسبقًا، انقلها بطريقة متسقة مع SQLite بعد إيقاف الكتابة وخذ نسخة احتياطية؛ تغيير المسار وحده ينشئ قاعدة فارغة.

اترك PORT للقيمة التي توفرها الاستضافة. لا تضف مفاتيح الخدمات إلا من لوحة متغيرات البيئة عند تفعيل التكاملات. عند ضبط PUBLIC_ORIGIN لا يقبل التطبيق إلا هذا المضيف وهذا الأصل، وتصبح كوكيز الجلسات Secure. دون المتغير يبقى الوصول محليًا. لا يعتمد التطبيق على X-Forwarded-Host أو X-Forwarded-Proto غير الموثوقين.

## التحقق بعد إعادة النشر

افتح الصفحة عبر HTTPS وأنشئ حساب المالك فور إتاحتها لأول مرة، ثم اختبر تسجيل الدخول والخروج. تحقق من بقاء الحساب بعد إعادة النشر. إنشاء أول مالك متاح لأول زائر حتى إتمام الإعداد، لذلك نفذ أول إعداد في نافذة نشر مراقبة أو خلف حماية وصول توفرها الاستضافة. راجع Runtime Logs إذا ظهر 503؛ نجاح البناء لا يثبت بدء السيرفر.

التشغيل المستمر للمجدول وعدد نسخ التطبيق واستمرار قرص SQLite تحتاج تحققًا من خطة الاستضافة؛ الاختبارات المحلية لا تثبت هذه الخصائص. شغّل نسخة تطبيق واحدة مع قاعدة SQLite الحالية.
